# 📚 Student Management System (Python Tkinter)

A desktop GUI application developed using Python and Tkinter for efficiently managing and tracking student records and details.

## 🛠️ Tech Stack & Tools
* **Language:** Python (`.py`)
* **GUI Library:** Tkinter
* **Environment:** Desktop / Local Windows Environment

## 🚀 Features
* User-friendly graphical interface (GUI) for easy navigation.
* Smooth handling of student data and input fields.
* Lightweight and fast desktop application performance.
